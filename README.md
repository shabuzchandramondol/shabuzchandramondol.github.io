# Shabuz Chandra Mondol — GitHub Pages

Portfolio website for **Shabuz Chandra Mondol**, Textile Engineer and Quality Assurance & Product Development professional.

## Files
- `index.html` — website structure/content
- `style.css` — responsive design and animations
- `script.js` — navigation, scroll reveal and progress bar
- `cv.pdf` — add the final CV PDF here
- `shabuz.jpg` — optional profile photo

## Publish on GitHub Pages
1. Create a repository named exactly `shabuzchandramondol.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and optionally `cv.pdf` and `shabuz.jpg`.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. The site will be available at `https://shabuzchandramondol.github.io/`.

## Add profile photo
Replace the placeholder inside `.portrait-card` in `index.html` with:
`<img src="shabuz.jpg" alt="Shabuz Chandra Mondol">`
and add CSS for `.portrait-card img` if desired.
